# Zen 专注模式

[English Documentation](zen-mode.md)

执行 `/toggle-zen-mode` 后，列出所有已打开 agent 的标签块让出它那一行。下方的分隔线保留，并继续汇报标签块原本承担的那一件事：其他 agent 里谁在运行、谁在等待回答、谁已完成、谁出错了。

```text
── ● ⠹ [+1] ────────────────────────────────────────────────────────────────

  对话区

── [ZEN] ────────────────────────────────────────────── Agent-03 ───────────
```

## 状态圆点

除当前聚焦的标签页外，每个处于运行中、等待回答、已完成或出错的标签页一个圆点，按标签顺序左对齐画在分隔线上；空闲标签页不贡献圆点，除非它有未读输出：

| 圆点 | 标签页状态 |
| --- | --- |
| `⠋ ⠙ ⠹ …` accent 色 | 运行中或思考中，工作期间不断推进帧 |
| `●` warning 色 | 该标签页上的[扩展对话框](tabs.zh.md#扩展对话框)正在等待回答 |
| `●` success 色 | 已完成，包括用 `/mark-done` 标记完成但尚未打开过的标签页 |
| `●` error 色 | 上一轮以错误结束 |

开头两段短横线与分隔线其余部分沿用分隔线自身的颜色，所以 zen 与编辑器边框读起来是同一个框。超过五个圆点后，其余折叠为 ` [+N]`；若连它也放不下，先去掉 `[+N]`、再去掉圆点，整行退化为一条普通分隔线，而不会被截断。

## 按键与切换

zen 开启时 `tab` 与 `shift+tab` 被吞掉。隐藏标签栏意味着失去显示焦点去向的界面，因此切换标签页只能刻意为之：

| 操作 | 方式 |
| --- | --- |
| 聚焦某个 agent | `/tab <序号\|标题>`，或退出 zen 后点击它的标签块 |
| 退出 zen | `/toggle-zen-mode` |
| 回到 Home | 输入框为空时 `left` 照常打开 Home；Home 会重新显示完整标签栏 |

补全弹窗打开时 `tab` 仍然用于补全；扩展的对话框在 zen 之前就接管了该按键。

## 状态迁移

zen 是随焦点迁移的每标签页标记，与 vim 模式相同：聚焦另一个 agent 时 zen 交给它，并在离开的 agent 上清除，同一时刻至多一个标签页处于 zen。打开标签页即聚焦它，所以用 `/new-session` 新建的标签页会从原持有者手中接过 zen。Home 是另一种界面而非标签页，因此打开 Home 会恢复完整标签栏，zen 仍留在它背后的 agent 上。关闭持有 zen 的标签页会连同 zen 一起结束，因为所属标签页已不存在。

zen 不写入标签页布局状态，因此启动时恢复的会话带完整标签栏。

输入卡片上边框的 `[ZEN]` 角标与 `[VIM]`、`[SHELL]` 并列标明该模式；终端过窄时，它和卡片其他模式角标一起消失。
